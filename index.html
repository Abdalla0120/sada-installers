How it installs

about 1 minute
  1. DownloadPick a tool below and save its setup file.
  2. Run itIf Windows SmartScreen warns you, choose More info then Run anyway.
  3. Pick RevitThe Revit versions on your PC are already ticked. Close those Revit sessions first.
  4. ActivateStart Revit, choose Always Load, and enter your SADA activation key.

Good to know

Where files go

Revit add-ins go to %APPDATA%\Autodesk\Revit\Addins\<year>. The ETABS Toolkit and File Renamer Pro go to %LOCALAPPDATA%\Programs. Struct Helper PC is portable: it runs from wherever you unzip it. The Android app installs like any APK.

Updating

Run the newer setup file over the old one. Your activation key and settings are kept.

Removing

Windows Settings > Apps > Installed apps, find the SADA tool, Uninstall. Close Revit first.

Activation keys

Struct, Steel and Arch are activated separately. The Parapet Tool uses the Struct key. The ETABS Toolkit and File Renamer Pro need no key.
